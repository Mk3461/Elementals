2D platform oyunu olarak gerçekleştirdiğimiz oyunumuz ilerleyip farklı niteliklere sahip düşmanlarla farklı saldırı biçimleriyle oyuncuya güzel deneyimler ve dakikalar yaşatıyor.Oyuna giriş ekranın ardından gelen karakter seçim ekranında farklı özelliklere ve saldırı biçimlerine sahip karakterlerden(Okçu,Yakın Dövüş) birini seçiyoruz ardından level seçme ekranında da mücadele etmek istediğimiz seviyeyi seçip ardından oyuna başlıyoruz farklı konumlanmış farklı özelliklere sahip düşmanlarla(Okçu,Yakın Dövüşçü,Şifacı,fireball spawner,boss) savaşarak oyunu bitirmeye çalışıyoruz.
